Passe o mouse sobre um pino para ver os alertas daquela estacao, ou clique para abrir direto aquela fazenda na aba Fazendas. As linhas amarelas mostram as divisas de pais e estado, as linhas brancas mostram as divisas de municipio (fonte: IBGE -- pode levar alguns segundos para carregar) e as linhas laranjas sao as rodovias BR-163, BR-364, BR-070 e BR-158 (fonte: OpenStreetMap). Os pinos azuis 📡 sao so as estacoes do INMET que estao realmente sendo usadas como base pra alguma fazenda (a mais proxima de cada uma, ou a escolhida manualmente na aba Fazendas) -- so como referencia de localizacao/cidade, os dados de clima do app vem da Open-Meteo.
